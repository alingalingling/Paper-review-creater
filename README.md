# 循证综述 浏览器版

在浏览器中运行的学术研究工作台。输入主题与写作要求，基于自己导入的文献生成有标题、章节、连贯段落及引用的完整综述。点击正文句子，右侧显示对应的高亮原文；支持连续对话修改、多研究会话、人工核验与导出。界面采用黑白灰配色、流动汉字背景与可暂停的开屏动画。

## 下载源码并运行

在 GitHub 点击 **Code → Download ZIP**，解压后先双击 `安装依赖.cmd`，再双击 `启动项目.cmd`。需要先安装 Python 3.10 或更新版本，并让终端能够使用 `python` 命令。

也可以通过 Git 获取：

```powershell
git clone https://github.com/alingalingling/Paper-review-creater.git
cd Paper-review-creater
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

macOS / Linux 可将最后两条命令中的 `.\.venv\Scripts\python.exe` 换成 `.venv/bin/python`。Windows 的 `.cmd` 启动脚本与本机 DPAPI 密钥保存仅适用于 Windows；其他系统可以在页面中临时填写密钥或使用环境变量。

源码附带两份明确标记的合成演示文本，可先体验原文摘录和证据定位。使用 AI 生成时，在页面右上角的模型设置中填写自己的 API Key。仓库不包含站主密钥、真实用户文献、会话记录、运行日志或隧道认证文件。字体文件及其许可随源码提供，无需在电脑上安装这些字体。

## 启动

需要 Python 3.10 或更新版本以及现代浏览器。无需 Node.js、数据库或前端构建步骤。界面使用本地 HTML、CSS、JavaScript，Python 提供文献处理与模型接口。

1. 双击 `启动项目.cmd`，程序启动本地服务并自动打开浏览器。
2. 默认地址为 `http://127.0.0.1:8765`；端口被占用时会选择其他可用端口，实际地址打印在启动窗口中。
3. 首次打开显示合成材料摘录。连接模型后，选择“AI 综述”并点击“生成综述”，即可得到分章节正文；点击正文任一句，右侧查看原文。
4. 选择“充分支持 / 部分支持 / 与原文矛盾 / 证据不足”，填写核验者后点击“保存核验结果”。
5. 点击右上角“导出综述”，浏览器下载包含完整综述 `review.md`、逐句审计 `audit.md`、JSON 和 CSV 的 ZIP 文件。

启动窗口需要保持开启。按 `Ctrl+C` 或关闭启动窗口可停止服务。本地模式将会话保存在当前操作系统用户的 `TraceReview/workspaces` 目录，使用原浏览器重新打开可继续；公网模式将研究保存在访客浏览器中，详见后文。Windows 模型连接可选择本机加密保存，重启后自动载入。切换到文献库，可点击或拖拽导入文献；证据账本页支持按核验状态筛选。项目菜单可恢复导出的 `ledger.json`，建议定期导出备份。

演示材料是项目自造的合成文本，含虚构数字，不能引用为真实文献。离线模式仅检索和摘录原文，不调用 AI，不冒充 AI 综述或真实实验结果。

## 导入真实文献

点击“导入文献”可多选 UTF-8 TXT、MD 和文字版 PDF，也可在文献库拖拽文件导入；单次文件合计不超过 35 MB。导入真实文献时会替换合成示例，之后导入则追加文献并按文件哈希去重。每次新增文献后需要重新生成草稿。首次使用 PDF 前双击 `安装依赖.cmd`，它会创建项目内的 `.venv` 并安装 `pypdf`；启动脚本优先使用此环境。

也可在本目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

PDF 记录的是从 1 开始的文件页序，不一定等于论文印刷页码。TXT/MD 按换页符 `\f` 分页；无换页符时记为一个文本页。字符位置使用提取文本中的 Python 字符索引，区间为 `[start, end)`，不是 PDF 页面坐标。

扫描件未接入 OCR；空白或无法提取文字的 PDF 页会给出提示。多栏、表格、公式的提取顺序可能影响证据，核验时仍需对照原 PDF。[pypdf 文字提取说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)

## 接入真实 AI

点击顶部的“模型设置”，填写：

- API 基础地址：DeepSeek 默认使用 `https://api.deepseek.com`。程序追加 `/chat/completions`。
- 模型名称：DeepSeek 默认使用 `deepseek-flash`，也可填写账户支持的其他模型。
- API Key：由本地 Python 服务使用；不在状态 API 中回传、不写入项目文件或导出账本。留空可保留已设置的密钥，也可勾选清除。

本机连接已配置时，工作台默认选中“AI 综述”，无需每次重新输入密钥。点击“测试连接”验证密钥和模型列表；这项检查不生成内容，也不保证账户余额足够，余额不足会在实际生成时明确提示。

勾选“在本机加密保存”后，连接信息通过 Windows 当前用户 DPAPI 加密，存入 `%LOCALAPPDATA%\TraceReview\model-settings.dpapi`，位于项目目录之外。换电脑或其他 Windows 用户通常需要重新配置。取消勾选只修改本次会话，不会删除已加密保存的旧设置；要清除持久密钥，应同时勾选“清除已保存的密钥”和“在本机加密保存”，再保存。

选择“AI 综述”，输入主题并点击“生成完整综述”。程序会向所配置的服务商发送主题与检索到的原文片段，可能产生服务商接口费用。模型直接组织章节与自然段落，段落仍绑定逐句证据；所有陈述必须在正文中出现且只能出现一次，否则不会替换当前草稿。材料充分时目标正文约 1200 至 2500 字，证据少时生成较短的完整结构，不添加无出处内容凑篇幅。无密钥时，离线模式只演示原文摘录、定位、核验和导出，不声称生成完整综述。

也支持进程环境变量，以下均为占位符，需替换：

```powershell
$env:TRACE_API_BASE = 'https://你的服务商地址/v1'
$env:TRACE_MODEL = '你的模型名称'
$env:TRACE_API_KEY = '你的密钥'
python app.py
```

接口需支持 `messages`、`temperature` 和 `choices[0].message.content`，返回正文为提示词要求的 JSON。DeepSeek 已启用 JSON 输出及非思考模式，输出上限为 12288 tokens，以容纳完整正文及逐句证据；其他兼容接口仍可通过设置使用。JSON 不合约定或被截断时会明确报错，不静默切换为离线演示。请求超时为 90 秒，密钥无效、余额不足、限流等分别显示原因。账本记录真实模型 ID、请求 ID 与服务商返回的 token 使用量，便于复查调用。

接口与参数依据：[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)、[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。

## 证据检查方式

每条陈述的证据保存文件 SHA-256、页序、逐字引文、文本快照 SHA-256 和字符起止位置。导出或重新打开账本时，依据快照重新检查定位。

自动检查包含：来源是否在导入集合中、页序是否存在、引文是否为对应页的逐字子串、文本快照哈希是否匹配。PDF 换行、空白、英文行尾断词、字体连字与全角字形导致的排版差异可自动映射回原文，保存的引文与字符位置始终对应未改动的文本快照；不接受改数字、删否定词或拼接不连续引文。缺少引文、假引文和无效页序都显示为定位未通过，不能人工标为“充分支持”。

**可定位只说明引文存在。** 因果、否定、数量、样本范围和跨文献综合是否成立，需要人工核验。程序不使用字符串相似度冒充语义正确率。每条陈述可以绑定多段证据；句子含多个事实时，人工必须检查全部事实。当前没有自动拆解原子命题，也没有自动语义裁决。

哈希用于发现文本变化，不能认证原论文的真实性，也不是防篡改签名。JSON 内含提取文本快照，可在原文件移动后复查；重新打开账本不会自动认证磁盘上的原文件。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `review.md` | 有标题、章节、连贯段落、句末引用和文献来源的综述正文 |
| `audit.md` | 逐句定位信息、原文引文、人工判定、证据缺口及统计 |
| `ledger.json` | 完整文献文本快照、检索片段、陈述和证据、核验历史、模型及提示词版本信息 |
| `ledger.csv` | 每条陈述一行，供人工检查；证据以 JSON 文本保留 |

所有生成陈述都保留，包括定位失败的陈述；不会把失败项删除后再报告成功率。稿件和人工核验会随会话自动保存，也可导出备份。模型密钥不导出，文献文本会导出。前端由 Python 后端调用模型。默认服务仅监听 `127.0.0.1`；公开部署通过下述独立运行模式和 Cloudflare Tunnel 转发。

统计中的 `location_rate` 为全部引文均有效的陈述数 / 全部陈述数；`annotation_rate` 为已人工核验数 / 全部陈述数；`supported_among_reviewed` 为充分支持且定位有效数 / 已核验数；`confirmed_support_lower_bound` 为充分支持且定位有效数 / 全部陈述数。分母为零时输出 `null`，避免把空结果算作 100%。这些是当前账本统计，不是研究性能结论。

## 命令行

在项目目录执行，无需启动 GUI：

```powershell
python -m trace_review --out outputs/demo
python -m trace_review --input "D:\文献目录" --topic "你的主题" --mode extract --out outputs/my-review
python -m trace_review --input "D:\文献目录" --topic "你的主题" --mode model --out outputs/ai-review
python -m unittest discover -s tests -v
```

安装依赖后也可将 `python` 替换为 `.\.venv\Scripts\python.exe`。命令行输出目录已有同名文件时会覆盖。网页导出交给浏览器下载管理器保存。

手动启动网页服务：

```powershell
python app.py
# 只启动服务，不自动打开浏览器
python web_app.py --no-browser --port 8765
```

```text
trace_review/core.py          文献导入、检索、AI 接口、定位检查、标注与导出
trace_review/article.py       章节段落结构、句子映射校验与整篇综述导出

```

当前是可运行的代码项目，未接入向量数据库、OCR、引文格式化、自动事实拆分或自动语义支持判定。真实 AI 端到端调用需要提供可用模型配置。

首次 AI 生成会按原文段落读取上下文，中文主题可以对应英文文献。材料在上下文预算内时全部提供给模型；较长的材料先调用模型生成中英文检索词，再从各篇文献选取相关段落及相邻上下文，原文预算为 36,000 字符。长文献的检索词转换会增加一次模型请求。检索词只用于筛选，证据仍来自导入的原始文本。字面未匹配不再直接跳过 AI；空稿会重试并在失败时保留原稿，不报告“正文 0 字”的成功结果。原文摘录模式仍按词项匹配，不调用付费模型。


### 按要求写作

在“研究主题”填写主题，在“写作要求”填写篇幅、重点、语气或段落要求，例如“正文不少于八百字，比较研究方法与局限”。支持中文及阿拉伯数字的字数上下限、区间和约数；也兼容直接在主题里写字数要求。正文字数按汉字、字母和数字计，不包含标题、标点及引用编号。

系统会检查正文长度与章节结构，最多自动调整两次。写作要求和实际字数随账本保存；若调整后仍未满足篇幅，会保留可用稿件并显示实际差距。不会将未满足的要求标记为已满足。


### 持续修改当前稿

已有 AI 综述后，输入区默认切换为“继续修改当前稿”。可以直接说“在结论最后加一句话，其他内容保持不变”，或者继续提问“把刚加的那句改得简洁些”。系统把当前稿件、初始要求和最近的对话一起传给模型，并用编辑补丁修改指定位置，保留其他句子及其人工核验记录。

句数限制只取本轮明确、肯定的要求：“只加一句”限制为一句，“至少三句/最多五句”按范围处理；“不要只加一句”“多加一些、详细描述”不会沿用历史单句限制。局部修改约束修改位置，允许在相关部分补充多句内容。

每轮追问都会按本轮要求、近期用户消息和主题重新检索整个文献集，补入此前没有引用过的页与相邻上下文。模型通过片段编号选择证据，服务器填入真实引文和页码；正文仍可概括、比较与解释。若引用选择失败，重试会带上具体失败位置、上一份补丁及可用片段，避免只重复一条笼统报错。

新增或改写的句子会重新定位引文并等待核验。“撤销上次修改”可以恢复修改前的稿件；对话、修改记录和撤销快照随 ledger.json 保存与恢复。只有点击“新建综述”进入生成表单后，才会重新生成全文。


### 对话与处理进度

首次输入采用居中的单列卡片：主题与写作要求依次排列，输入内容较长时自动扩展高度；文献、模式和生成操作集中在底部。尚无稿件时不展示重复的空白正文区域。提交主题后，输入卡片通过过渡动效展开成上方完整对话区。后续可以在聊天输入框中连续提问或局部修改，下方继续保留正文和来源对照。“新对话”返回首次输入。聊天区 Enter 发送、Shift + Enter 换行，也保留 Ctrl + Enter 快捷键；中文输入法选词期间不会误发送。

聊天中显示后端实际执行的处理阶段（检索、生成、结构与引用校验、篇幅调整、局部补丁等），完成后可展开每条回复的“处理过程”。这些是可核对的工作进度，不是模型的内部思维链；不请求或展示私密推理字段。处理记录与对话一并保存至账本。

对话区会记住各会话在本次页面访问中的阅读位置。停在底部时跟随新回复和处理进度，上翻历史时保持当前位置；发送与完成不再重播从顶部滚到底部的动画。可运行 `python -m tests.scroll_fixture` 打开 `http://127.0.0.1:8766` 验证长对话、进度更新及会话切换；该测试使用内存中的演示会话和模拟回复，不调用模型或修改已保存稿件。


## 字海与多会话

- 开屏使用 Noto Sans SC（思源黑体系列）的粗体标题「让每一句话，都有来处」，上方配英文「Every sentence. A source.」，桌面横向展开、手机分成两行，并保留逐字浮现与微光扫过。向下滚动、手机上向上滑动，或点击底部箭头即可进入研究空间；也支持方向下键、Page Down 和页面空格键。项目附带标题字形子集 `web/fonts/trace-title-sans.woff2`，无需联网加载字体，许可与说明保存在同目录。标题和箭头动效随「暂停动效」和系统减少动态效果设置一起停用。
- 写作、处理进度、文献、来源核验、账本和设置使用统一的黑白灰配色；错误提示保留浅红色。阅读区域采用实色深灰底，辅助文字与控件边界提高对比度，背景字海在研究空间内进一步淡化。
- 「阅读原文」窗口的文件名、关闭按钮和换行开关固定在顶部，只有正文滚动；可随时点击关闭或按 Esc 返回。PDF 默认连续排版，TXT/Markdown 默认保留换行，可通过开关切换。该设置只改变阅读显示，不修改原始提取文本、引文或定位偏移；每次打开从第一页开始。
- 首页采用黑色满屏汉字流与居中标题，四套自托管字体分成远、中、近三层，以不同速度缓慢下移、小幅摆动。背景使用 Ma Shan Zheng、Zhi Mang Xing、Liu Jian Mao Cao、ZCOOL XiaoWei 的重命名字形子集，四个 WOFF2 文件合计约 93 KB，许可与来源在 `web/fonts`。无需设备安装字体，也不需要访问外部字体 CDN。字体加载完成后才绘制 Canvas 字形图集；慢到的字体到达后会重绘，失败的字体不会被固化为系统默认字体。
- 两侧半透明飘带以错开的节奏连续起伏、翻转，文字独立闪亮、渐隐；透视投影和鼠标视差表现空间纵深。鼠标带动白色反相光圈，并保留轻微拖尾。进入后字海与飘带淡化，写作界面统一为黑白灰；点击品牌或「字海」可重播开场。「暂停背景」及系统减少动态效果设置仍然有效。
- 页面加载时显示统一的书页标识与细线过渡；研究数据准备好后，主界面整体淡入，不展示空侧栏和半成品正文。字体最多阻塞开场 2.5 秒，之后可继续进入空间；迟到字体自动补齐。历史聊天恢复时不逐条重播入场动画，网络较慢时提供重新加载入口。可运行 `python -m tests.presentation_fixture --delay 8` 在本地独立演示慢加载；`node --test tests/presentation.test.cjs` 覆盖字体加载顺序、失败回退及界面就绪条件。
- 左侧「新的研究」创建独立会话，沿用当前文献的副本，正文和对话从空白开始；每个会话有独立的生成进度、稿件、引用、批注和撤销记录。切换到别的会话不会中断后台生成。
- 本地 `8765` 工作台的会话自动保存到 `%LOCALAPPDATA%\TraceReview\workspaces`，重启服务后使用原浏览器可继续打开。密钥单独由系统加密保存，不写入会话文件；源码包不包含会话资料。公开站采用下述浏览器存储方式。
- 生成期间刷新页面可重新看到处理进度；服务进程需要保持运行。可继续使用「导出」备份当前会话的综述与证据账本。

## review.njfu.org 公开部署

本节说明项目现有站点的部署方式。下载源码后只在本机使用时，无需 Cloudflare。`scripts/public_site.py` 和 `scripts/verify_public_site.py` 中的域名与隧道名称是现有站点的配置；部署自己的站点前须改成自己的域名、隧道和配置文件，不要直接复用。

当前部署由这台 Windows 电脑运行 Python 后端，Cloudflare Tunnel 提供 HTTPS 域名连接。电脑关机、休眠或断网后网站无法使用；关闭浏览器不会停止服务。

- 双击 `启动公网.cmd` 启动后台服务；双击 `停止公网.cmd` 停止公开站。电脑重启后需重新启动公网脚本。本地 `8765` 工作台独立运行。
- 访客在「模型连接」中填写自己的 DeepSeek API Key，费用由访客账户承担。公开模式从不读取站主密钥；访客密钥仅保留在当前页面内存中，刷新后需重新填写。仅在生成、修改或测试连接时临时发送到后端，处理结束即释放；不写入浏览器数据库、磁盘、账本或响应。公开接口固定为 DeepSeek 官方地址。
- 公开站需要通过 HTTPS 使用浏览器存储协调功能。经过 Cloudflare Tunnel 的 HTTP 访问会自动跳转 HTTPS；本机 `localhost` / `127.0.0.1` 预览仍可使用 HTTP。
- 文献提取文本、综述、对话、批注、撤销记录和未发送草稿保存于访客浏览器的 IndexedDB（`trace-review-workspace`）；左侧显示「本机保存」。阅读、切换研究和查看引用直接读取本机数据。相同浏览器配置下的同一站点共享研究，多个页面的修改通过锁及版本检查避免相互覆盖；不同浏览器、设备和站点地址不自动同步。
- 你的电脑仍负责提供网页、临时解析文献、导出文件和转发 AI 请求，模型运算由 DeepSeek 执行。任务结果在浏览器确认写入后释放；未领取的完成结果最多暂留 5 分钟。服务器重启不会删除已存入浏览器的稿件，但会中断尚未完成的任务。生成时建议保持页面打开。
- 浏览器清除站点数据、无痕窗口关闭或存储空间被回收，都可能清掉本机记录。请用「导出」备份；`ledger.json` 可通过项目菜单恢复。浏览器空间不足时保留当前页面的新结果并提示先导出，不把未保存结果当作保存成功。
- 已有公网稿件首次刷新时按原会话 Cookie 自动迁入浏览器。`%LOCALAPPDATA%\TraceReview\public-workspaces` 中的旧副本暂保留，不自动删除。升级前打开的旧页面继续兼容旧存储，请刷新以启用本机保存；新版浏览器任务不会写入该目录。本地 `8765` 工作台不受此迁移影响。
- 请求提交后只轮询小体积进度，完成时取回一次稿件；刷新或切换研究不重复提交。服务器同时处理最多 2 个任务，临时任务槽位共 4 个；每个来源 IP 每小时最多提交 30 次写作请求，每分钟最多 60 次修改操作。每项研究最多 40 篇文献、400 万文本字符。
- 后台管理器会重启意外退出的 Python 服务或连接程序。运行日志、隧道配置和进程状态保存在 `%LOCALAPPDATA%\TraceReview\deployment`。隧道凭据位于 `%USERPROFILE%\.cloudflared`；这些目录不包含在源码包内。

管理命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/public_site.py start
.\.venv\Scripts\python.exe -X utf8 scripts/public_site.py status
.\.venv\Scripts\python.exe -X utf8 scripts/public_site.py stop
```

`scripts/verify_public_site.py` 使用独立测试 Cookie 和合成文本验证公开站的静态资源、浏览器存储模式、临时导入、摘录生成、任务隔离、结果释放及导出，不调用付费模型；结果写入 `outputs/deployment-verification.json`。后端回归：`python -m unittest discover -s tests`；浏览器存储状态机回归：`node --test tests/browser-storage.test.cjs`。

新电脑部署时，需重新安装 Cloudflare 官方 `cloudflared`、完成账号授权并准备该电脑的隧道配置；启动脚本不会打包或复制认证凭据。配置步骤见 [Cloudflare 官方 Tunnel 文档](https://developers.cloudflare.com/tunnel/features/locally-managed-tunnels/create-local-tunnel/)。
